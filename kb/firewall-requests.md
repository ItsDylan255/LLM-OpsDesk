# Firewall-Freigaben beantragen / firewall change requests

keywords: firewall, port, freigabe, öffnen, open port, regel, rule, change request, änderung, testserver, test server, zugriff

## Ablauf
1. Quelle, Ziel, Port und Protokoll angeben (z. B. TCP 8443 von Netz X zu test07).
2. Zweck und Dauer der Freigabe nennen (befristet für Tests?).
3. Freigabe durch Verantwortlichen, Umsetzung im nächsten Änderungsfenster.

## Hinweise
Nur so viel freigeben wie nötig. Testfreigaben mit Ablaufdatum versehen.
